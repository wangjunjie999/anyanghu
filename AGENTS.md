# Architecture rules
- Keep the real product catalog, series metadata and derived homepage showcases in `src/data/products.ts`; pages consume this module so official names and parameters cannot drift between displays.
- Keep catalog rule tests beside the data module and run them with `bun test src/data/products.test.ts`; these protect official names, series counts, specifications and parameters without testing presentation.
- Site motion: homepage scenes are scroll-linked via `motion/react` (useScroll/useTransform motion values, sticky scenes in `src/components/scroll/`, native scroll, no snapping or smooth-scroll libs); elsewhere one-shot primitives (`Reveal`, `SplitText`, `CountUp`, `TiltCard`, `src/hooks/use-motion.ts`). Transform/opacity only, no React re-render per scroll frame, prefers-reduced-motion renders static layout; WebGL (CircularGallery) desktop-only.
